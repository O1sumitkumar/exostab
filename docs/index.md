# exostab

**Is this planetary system dynamically stable?** exostab answers the question for any known multi-planet system
with three indicators (Hill spacing, angular momentum deficit, and N-body integration with the MEGNO chaos
indicator). It takes its parameters from the NASA Exoplanet Archive and shows every assumption it made.
